# 论证点评间 · 异地版（Windows 一键部署）

用一台**迷你电脑**当中继服务器，让两个朋友（手机 / 平板 / 电脑都行）**在不同地方**打开同一个网址，实时异地聊天。完整保留了网页版的全部功能（口令条、多选总结、历史存档、结束自动存档、未结束恢复、复盘进度条固定等），AI 用你自己浏览器里的 Key（BYOK，不出本机）。

**本版新增（论证点评）**：房间栏的「⚖️ 整理 / 点评」可切换**论证点评玩法**——总结时由 AI 做**多维度论证评估报告**（🔬逻辑 / 🗣语言 / 🏛体系 / 🌟价值 / 🕳漏洞把控，各维度 0-10 分 + 总体评分 + 详尽的公正评价 + 改进建议 + 🔁反方反驳视角），并附带 **❓ AI 质询反问**帮发言者补强论证。「整理」模式保留原有「中立整理」总结玩法，两种随时互切。

**右上角版本号 = 在线自动更新**：点它即从 GitHub 仓库拉取最新版本并覆盖本机（服务器环境自动检查，发现新版自动更新并刷新）。

本包帮你自动：启动中继服务器 → 起 Cloudflare 隧道 → **把每次的新网址发邮件到你邮箱**（不在电脑旁也能拿到地址）。

---

## 一、开始前准备

| 需要 | 说明 |
|---|---|
| **Node.js**（LTS） | https://nodejs.org 下载 LTS 版安装 |
| **一个邮箱的 SMTP 授权码** | 用于把新地址推送给你（QQ/163 等，见下） |
| **（可选）DeepSeek Key** | 想要真实 AI 总结时，在聊天页面「真实 AI · DeepSeek」里填 |

> 不需要公网 IP、不需要域名、不需要路由器设置。DeepSeek Key 只需在页面里填，不出现在服务器上。

### 拿邮箱授权码（QQ / 163 二选一）
- **QQ 邮箱**：网页版 → 设置 → 账户 → 开启 SMTP 服务 → 生成授权码。（`smtp.qq.com`，端口 `465`）
- **163 邮箱**：设置 → POP3/SMTP/IMAP → 开启 → 客户端授权码。（`smtp.163.com`，端口 `465`）

## 二、安装（首次）

1. 把整个文件夹拷贝到迷你电脑（如 `D:\discussion-room`）。
2. 双击 **`install-menu.bat`**，选 **`1` 一键初始化**（会自动：设 npm 国内镜像、装依赖、下载 cloudflared、生成邮箱配置模板）。
3. 编辑邮箱配置：选 **`5`** 打开 `push-config.json`，填 `host/user/pass(from)/to`，保存。
   > **`to` 是「收件人数组」，支持同时填多个邮箱**（如双方各自的邮箱）：把新网址**同时推送给每一位**，一方电脑启动后两人都能直接收到最新地址，无需互相转发。格式：`"to": ["邮箱A@xx.com", "邮箱B@yy.com"]`。
4. 选 **`4` 发一封测试邮件**：能收到就说明邮箱配置 OK。
5. （可选）想用真实 AI，启动后进页面，在「🤖 真实 AI·DeepSeek」粘贴你的 Key 并保存。

---

## 三、启动 / 开机自启

**方式 A · 手动**：双击 **`start.bat`**。看到 `🎉 你的聊天室新网址：https://xxx.trycloudflare.com` 即成功，邮箱也会收到同一地址。把网址发给好友即可开聊。窗口保持开着（Ctrl+C 停止）。

**方式 B · 开机自启（推荐）**：`install-menu.bat` 选 **`2`**。之后每次登录 Windows 自动启动服务，并把新网址发到你邮箱。日志在 `autostart.log`。取消用选 `3`。

---

## 四、好友怎么进

好友用**手机 / 平板 / 电脑的浏览器**打开你发的 `https://xxx.trycloudflare.com`：
- 一方点「**＋ 创建讨论间**」填昵称进入，顶部会显示 6 位**房间口令**；
- 另一方点「**🔑 我有口令**」，输昵称 + 口令即可加入同房间，实时聊天。

---

## 五、重要说明

- **地址每次重启会变**：迷你电脑关机/隧道断开后网址变化，开机时会收到新地址，再发好友即可。
- **迷你电脑关机时连不上**：适合"约好时间一起聊"；想让好友随时进需保持常开。
- **AI Key**：在各自浏览器里填自己的 DeepSeek Key，不发送到服务器（BYOK）。不填则用内置模拟 AI。
- **安全**：知道网址即可进入，只发给信任好友；邮箱授权码只在本机 `push-config.json`，勿外传。
- **国内加速**：依赖下载用 npm 镜像、cloudflared 用国内镜像（脚本已内置，失败自动回退官方源）。想手动设 npm 镜像：`npm config set registry https://registry.npmmirror.com`。

---

## 常见问题

- **cloudflared 下载失败** → 手动去 github.com/cloudflare/cloudflared/releases 下 `cloudflared-windows-amd64.exe`，改名 `cloudflared.exe` 放本目录。
- **收不到地址邮件** → 用选 `4` 测测试邮件；多半授权码/smtp 问题。
- **聊天页面能开但不同步** → 确认两人进的是**同一个房间口令**。
